Box Model

Cada elemento HTML se calcula como una caja formada por contenido, padding, borde y margen.

Como se organiza una caja

margin
border
padding
content
  • content: texto, imagen o contenido del elemento.
  • padding: espacio interno entre el contenido y el borde.
  • border: limite visual de la caja.
  • margin: espacio externo entre cajas.

La regla box-sizing

box-sizing: border-box incluye el padding y el borde dentro del ancho y alto declarados.

content-box

El tamano declarado solo mide el contenido.

border-box

El tamano declarado incluye contenido, padding y borde.
