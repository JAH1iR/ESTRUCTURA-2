60 - Async/Await (Forma moderna)

¿Qué es Async/Await?

Async/Await hace que el código asincrónico se lea como si fuera sincrónico. Es la forma más moderna de manejar promesas.

// Sintaxis: async function miFunc() { try { const resultado = await unaPromesa(); console.log(resultado); } catch (error) { console.error(error); } }

Ventajas de Async/Await

  • ✓ Código más legible y limpio
  • ✓ Se parece a código sincrónico
  • ✓ Manejo de errores con try/catch

// Con .then() fetch(url) .then(r => r.json()) .then(data => console.log(data)) .catch(e => console.error(e)); // Con Async/Await (más limpio) async function obtener() { try { const r = await fetch(url); const data = await r.json(); console.log(data); } catch (e) { console.error(e); } }
