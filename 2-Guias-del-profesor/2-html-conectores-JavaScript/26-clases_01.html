26 - Clases en JavaScript

¿Qué es una Clase?

Una clase es como un PLANO o MOLDE para crear objetos. Define propiedades y métodos que tendrán todos los objetos creados desde esa clase.

class NombreClase { constructor(parametros) { this.propiedad = parametro; } metodo() { // código del método } } let objeto = new NombreClase(argumentos);

Partes de una Clase

  • Constructor: Se ejecuta cuando creas un objeto (new). Inicializa las propiedades.
  • Propiedades: Variables del objeto (nombre, edad, precio)
  • Métodos: Funciones del objeto (hablar, mover, calcular)

Ejemplo 1: Clase Persona

class Persona { constructor(nombre, edad) { this.nombre = nombre; this.edad = edad; } presentarse() { console.log("Hola, me llamo " + this.nombre); } } let persona1 = new Persona("Juan", 30); let persona2 = new Persona("María", 25); persona1.presentarse(); // Hola, me llamo Juan persona2.presentarse(); // Hola, me llamo María

Ejemplo 2: Clase Auto

class Auto { constructor(marca, modelo, velocidad = 0) { this.marca = marca; this.modelo = modelo; this.velocidad = velocidad; } acelerar() { this.velocidad += 10; } frenar() { this.velocidad -= 10; } mostrarInfo() { console.log(this.marca + " " + this.modelo + " - Velocidad: " + this.velocidad); } } let miAuto = new Auto("Toyota", "Corolla"); miAuto.acelerar(); miAuto.mostrarInfo();

Ejemplo 3: Clase CuentaBancaria

class CuentaBancaria { constructor(titular, saldoInicial = 0) { this.titular = titular; this.saldo = saldoInicial; } depositar(cantidad) { this.saldo += cantidad; return "Deposito realizado. Nuevo saldo: $" + this.saldo; } retirar(cantidad) { if (cantidad <= this.saldo) { this.saldo -= cantidad; return "Retiro realizado. Nuevo saldo: $" + this.saldo; } return "Saldo insuficiente"; } } let cuenta = new CuentaBancaria("Pedro", 1000);

Ejemplo 4: Clase Estudiante

class Estudiante { constructor(nombre, carrera, semestre) { this.nombre = nombre; this.carrera = carrera; this.semestre = semestre; this.calificaciones = []; } agregarCalificacion(calificacion) { this.calificaciones.push(calificacion); } calcularPromedio() { let suma = this.calificaciones.reduce((a, b) => a + b, 0); return suma / this.calificaciones.length; } }

Clase vs Objeto Literal

Objeto Literal: Un objeto único

let persona = { nombre: "Juan", edad: 30 };

Clase: Un molde para crear múltiples objetos similares

class Persona { constructor(nombre, edad) { this.nombre = nombre; this.edad = edad; } } let persona1 = new Persona("Juan", 30); let persona2 = new Persona("María", 25); let persona3 = new Persona("Carlos", 35);
