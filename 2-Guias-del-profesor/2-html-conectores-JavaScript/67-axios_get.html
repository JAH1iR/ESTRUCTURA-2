67 - Axios - Librería HTTP

Nota: Axios es una librería que simplifica las peticiones HTTP. Para usarla, necesita ser importada desde un CDN.

¿Qué es Axios?

Axios es una librería JavaScript que facilita hacer peticiones HTTP. Tiene ventajas sobre Fetch:

  • ✓ Sintaxis más simple
  • ✓ Manejo de errores más consistente
  • ✓ Timeout automático
  • ✓ Interceptores integrados
  • ✓ Cancelación de peticiones

Instalación y uso

// CDN <script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script> // npm npm install axios

Sintaxis básica

// GET axios.get('url') .then(response => console.log(response.data)) .catch(error => console.error(error)); // POST axios.post('url', { datos }) .then(response => console.log(response.data)) .catch(error => console.error(error)); // Configuración axios({ method: 'GET', url: 'url', headers: { 'Authorization': 'Bearer token' } })

Ejemplo 2: Comparación Fetch vs Axios

// FETCH fetch(url) .then(r => r.json()) .then(data => console.log(data)) .catch(e => console.error(e)); // AXIOS (más simple) axios.get(url) .then(r => console.log(r.data)) .catch(e => console.error(e));

Métodos disponibles en Axios

  • axios.get(url): Obtener datos
  • axios.post(url, data): Enviar datos
  • axios.put(url, data): Actualizar completo
  • axios.patch(url, data): Actualizar parcial
  • axios.delete(url): Eliminar
