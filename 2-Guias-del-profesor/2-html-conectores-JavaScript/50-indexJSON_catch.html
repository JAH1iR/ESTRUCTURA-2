50 - Fetch API - Manejo de Errores

¿Cómo manejar errores en Fetch?

El .catch() se ejecuta cuando hay un error en la petición.

fetch(url) .then(response => { if (!response.ok) { throw new Error('Error HTTP: ' + response.status); } return response.json(); }) .then(data => console.log(data)) .catch(error => console.error('Error:', error.message));

Mejores prácticas de manejo de errores

  • ✓ Siempre usar .catch() o try/catch
  • ✓ Verificar response.ok antes de procesar
  • ✓ Mostrar mensajes claros al usuario
  • ✓ Registrar errores para debugging
  • ✓ Usar finally para limpiar recursos
