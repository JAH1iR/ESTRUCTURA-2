25 - Introducción a Programación Orientada a Objetos (POO)

¿Qué es POO?

La Programación Orientada a Objetos es un paradigma de programación que organiza el código usando OBJETOS con propiedades y métodos.

Conceptos clave:

  • Objeto: Una entidad que tiene propiedades (datos) y métodos (acciones)
  • Propiedades: Características del objeto (nombre, edad, color)
  • Métodos: Acciones que puede hacer el objeto (hablar, mover, saltar)

Ejemplo 1: Objeto simple (Persona)

let persona = { nombre: "Juan", edad: 30, ciudad: "Madrid", presentarse: function() { console.log("Me llamo " + this.nombre + " y tengo " + this.edad + " años"); } }; persona.presentarse();

Ejemplo 2: Objeto Auto

let auto = { marca: "Toyota", modelo: "Corolla", velocidad: 0, acelerar: function() { this.velocidad += 10; }, frenar: function() { this.velocidad -= 10; }, mostrarVelocidad: function() { console.log("Velocidad: " + this.velocidad + " km/h"); } }; auto.acelerar(); auto.mostrarVelocidad(); // 10 km/h auto.acelerar(); auto.mostrarVelocidad(); // 20 km/h

Ejemplo 3: Objeto Banco (Cuenta)

let cuenta = { titular: "Pedro", saldo: 1000, depositar: function(cantidad) { this.saldo += cantidad; console.log("Deposito de " + cantidad + ". Nuevo saldo: " + this.saldo); }, retirar: function(cantidad) { if (cantidad <= this.saldo) { this.saldo -= cantidad; console.log("Retiro de " + cantidad + ". Nuevo saldo: " + this.saldo); } else { console.log("Saldo insuficiente"); } }, mostrarSaldo: function() { console.log("Saldo de " + this.titular + ": $" + this.saldo); } };

Ejemplo 4: Objeto Libro

let libro = { titulo: "JavaScript Avanzado", autor: "Kyle Simpson", año: 2014, páginas: 512, información: function() { console.log(this.titulo + " por " + this.autor + " (" + this.año + ")"); }, resumen: function() { console.log(this.titulo + " tiene " + this.páginas + " páginas"); } };

Ventajas de los Objetos

  • Organización: Agrupa datos relacionados
  • Reutilización: Un objeto se puede usar múltiples veces
  • Mantenibilidad: Fácil de actualizar todas las propiedades
  • Realismo: Refleja objetos del mundo real

Accediendo a propiedades y métodos

let persona = { nombre: "María", edad: 25, saludar: function() { console.log("Hola"); } }; // Accediendo a propiedades console.log(persona.nombre); // María console.log(persona.edad); // 25 // Accediendo a métodos (con paréntesis) persona.saludar(); // Hola // Modificando propiedades persona.edad = 26;
