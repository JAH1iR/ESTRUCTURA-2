39 - Propiedades de la Pantalla (Screen Object)

¿Qué es el objeto Screen?

El objeto Screen contiene información sobre la pantalla del usuario: resolución, ancho, altura, colores, etc.

Propiedades principales

console.log(screen.width); // Ancho en píxeles console.log(screen.height); // Altura en píxeles console.log(screen.colorDepth); // Profundidad de color console.log(screen.pixelDepth); // Profundidad de píxeles console.log(screen.availWidth); // Ancho disponible (sin barra) console.log(screen.availHeight); // Altura disponible (sin barra)
