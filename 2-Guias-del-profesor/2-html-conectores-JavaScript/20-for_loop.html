20 - Ciclo For

¿Qué es un ciclo For?

Un ciclo for es más compacto que while. Combina inicialización, condición e incremento en una línea.

for (inicialización; condición; incremento) { // código a repetir } // Ejemplo: contar de 1 a 5 for (let i = 1; i <= 5; i++) { console.log(i); }

Partes del ciclo For

for (let i = 1; // 1. INICIALIZACIÓN: crear variable i <= 5; // 2. CONDICIÓN: mientras sea verdadera i++) // 3. INCREMENTO: después de cada iteración { console.log(i); // código }

Ejemplo 1: Contar hasta un número

for (let i = 1; i <= 5; i++) { console.log(i); }

Ejemplo 2: Cuenta regresiva

for (let i = 10; i >= 1; i--) { console.log(i); } console.log("¡Despegue!");

Ejemplo 3: Tabla de multiplicar

for (let i = 1; i <= 12; i++) { console.log("7 x " + i + " = " + (7 * i)); }

Ejemplo 4: Sumar números pares

let suma = 0; for (let i = 2; i <= 20; i += 2) { suma += i; } console.log("Suma de pares: " + suma);

Ejemplo 5: Asteriscos (patrón)

for (let i = 1; i <= 5; i++) { let asteriscos = ""; for (let j = 1; j <= i; j++) { asteriscos += "* "; } console.log(asteriscos); }

Ejemplo 6: For con paso diferente

Puedes cambiar el incremento (i++, i+=2, i+=5, etc.)

for (let i = 0; i <= 20; i += 3) { console.log(i); // 0, 3, 6, 9, 12, 15, 18 }
