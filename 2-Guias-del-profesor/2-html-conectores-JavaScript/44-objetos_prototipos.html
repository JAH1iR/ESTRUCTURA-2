44 - Objetos y Prototipos Avanzado

Métodos útiles con objetos

  • Object.keys(): Obtiene las claves de un objeto
  • Object.values(): Obtiene los valores de un objeto
  • Object.entries(): Obtiene pares clave-valor
  • Object.assign(): Copia propiedades de un objeto a otro
  • Object.create(): Crea un objeto con prototipo específico

Ejemplo 1: Object.keys(), values(), entries()

let persona = { nombre: "Juan", edad: 30, ciudad: "Madrid" }; console.log(Object.keys(persona)); // ["nombre", "edad", "ciudad"] console.log(Object.values(persona)); // ["Juan", 30, "Madrid"] console.log(Object.entries(persona)); // [["nombre","Juan"], ["edad",30], ...]

Ejemplo 2: Object.assign() - Copiar y fusionar

let obj1 = { a: 1, b: 2 }; let obj2 = { c: 3, d: 4 }; let fusion = Object.assign({}, obj1, obj2); console.log(fusion); // { a: 1, b: 2, c: 3, d: 4 }

Ejemplo 3: hasOwnProperty() - Verificar propiedad

let auto = { marca: "Toyota", modelo: "Corolla" }; console.log(auto.hasOwnProperty("marca")); // true console.log(auto.hasOwnProperty("precio")); // false

Ejemplo 4: Extender prototipo de Array

// Agregar método personalizado a Array Array.prototype.suma = function() { return this.reduce((a, b) => a + b, 0); }; let numeros = [1, 2, 3, 4, 5]; console.log(numeros.suma()); // 15
