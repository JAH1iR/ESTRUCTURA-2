14 - Condicionales If-Then-Else

¿Qué es un condicional If-Then-Else?

Un condicional permite ejecutar código diferente según si una condición es verdadera o falsa.

if (condición) { // se ejecuta si es verdadero } else { // se ejecuta si es falso }

Ejemplo 1: Verificar edad

let edad = 18; if (edad >= 18) { console.log("Eres mayor de edad"); } else { console.log("Eres menor de edad"); }

Ejemplo 2: Número positivo o negativo

let numero = -5; if (numero > 0) { console.log("El número es positivo"); } else if (numero < 0) { console.log("El número es negativo"); } else { console.log("El número es cero"); }

Ejemplo 3: Calificación según nota

let nota = 85; if (nota >= 90) { console.log("Excelente"); } else if (nota >= 80) { console.log("Muy Bien"); } else if (nota >= 70) { console.log("Bien"); } else if (nota >= 60) { console.log("Regular"); } else { console.log("Insuficiente"); }

Ejemplo 4: Validar contraseña

let contraseña = "abc123"; let ingresada = "abc123"; if (contraseña === ingresada) { console.log("Acceso permitido"); } else { console.log("Contraseña incorrecta"); }
