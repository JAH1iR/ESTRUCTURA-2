49 - Fetch API - Obtener Datos (GET)

¿Qué es Fetch?

Fetch es una API moderna de JavaScript para hacer peticiones HTTP. Reemplaza XMLHttpRequest.

fetch(url) .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error("Error:", error));

Pasos de Fetch

  1. fetch(url): Hace la petición
  2. .then(response): La respuesta llega
  3. response.json(): Convierte a JSON
  4. .then(data): Recibimos los datos
  5. .catch(error): Manejar errores
