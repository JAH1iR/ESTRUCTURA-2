23 - Funciones sin Parámetros

¿Qué es una función?

Una función es un bloque de código reutilizable que ejecuta una tarea específica.

// Definir función (sin parámetros) function saludar() { console.log("Hola"); } // Llamar la función saludar(); // Imprime: Hola saludar(); // Imprime: Hola

Sintaxis de funciones sin parámetros

function nombreFuncion() { // código a ejecutar } nombreFuncion(); // Llamar la función

Ejemplo 1: Saludo simple

function saludar() { console.log("¡Hola!"); } saludar(); // Llama la función

Ejemplo 2: Mostrar fecha

function mostrarFecha() { let fecha = new Date(); console.log(fecha); } mostrarFecha();

Ejemplo 3: Presentarse

function presentarse() { console.log("Mi nombre es Pedro"); console.log("Tengo 25 años"); console.log("Soy programador"); } presentarse();

Ejemplo 4: Mostrar menú

function mostrarMenu() { console.log("===== MENÚ ====="); console.log("1. Inicio"); console.log("2. Galería"); console.log("3. Contacto"); console.log("4. Salir"); console.log("================"); } mostrarMenu();

Ejemplo 5: Información del navegador

function mostrarInfoNavegador() { console.log("Navegador: " + navigator.userAgent); console.log("Idioma: " + navigator.language); console.log("Plataforma: " + navigator.platform); } mostrarInfoNavegador();

Ventajas de las funciones

  • Reutilización: Una función se puede llamar múltiples veces
  • Organización: Divide el código en bloques lógicos
  • Mantenibilidad: Fácil de actualizar y corregir
  • Legibilidad: El código es más claro y entendible
