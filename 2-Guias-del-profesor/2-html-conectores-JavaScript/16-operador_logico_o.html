16 - Operadores Lógicos OR (||)

¿Qué es el operador OR (||)?

El operador OR (||) retorna verdadero si AL MENOS UNA de las condiciones es verdadera.

if (condición1 || condición2) { // se ejecuta si AL MENOS UNA es verdadera }

Tabla de Verdad - OR (||)

Condición 1 Condición 2 Resultado (||)
Verdadero Verdadero Verdadero
Verdadero Falso Verdadero
Falso Verdadero Verdadero
Falso Falso Falso

Ejemplo 1: Identidades permitidas

Se permite entrada con cédula O pasaporte

let tieneCedula = true; let tieneP asaporte = false; if (tieneCedula || tieneP asaporte) { console.log("Puedes entrar"); } else { console.log("Necesitas cédula o pasaporte"); }

Ejemplo 2: Descuento para cliente especial

Descuento si eres estudiante O jubilado O tienes tarjeta VIP

let esEstudiante = true; let esJubilado = false; let tieneVIP = false; if (esEstudiante || esJubilado || tieneVIP) { console.log("¡Tienes 15% de descuento!"); } else { console.log("Sin descuento"); }

Ejemplo 3: Día libre (fin de semana O feriado)

let dia = "sábado"; let esFeriado = false; if (dia === "sábado" || dia === "domingo" || esFeriado) { console.log("¡Día libre!"); } else { console.log("Es día de trabajo"); }

Ejemplo 4: Acceso a contenido

Puedes acceder si eres administrador O si tienes permiso especial

let esAdmin = false; let tienePermiso = true; if (esAdmin || tienePermiso) { console.log("Acceso permitido"); } else { console.log("No tienes permisos"); }
