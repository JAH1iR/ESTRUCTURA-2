18 - Ciclo While

¿Qué es un ciclo While?

Un ciclo while repite un bloque de código mientras una condición sea verdadera.

while (condición) { // código a repetir // IMPORTANTE: cambiar la condición para evitar bucle infinito }

Ejemplo 1: Contar hasta un número

let i = 1; while (i <= 5) { console.log(i); i++; // incrementar }

Ejemplo 2: Restar hasta cero

let numero = 5; while (numero > 0) { console.log(numero); numero--; // decrementar } console.log("¡Despegue!");

Ejemplo 3: Sumar números

let suma = 0; let i = 1; while (i <= 10) { suma += i; // suma = suma + i i++; } console.log("Suma de 1 a 10: " + suma); // 55

Ejemplo 4: Tabla de multiplicar

let numero = 5; let multiplicador = 1; while (multiplicador <= 12) { console.log(numero + " x " + multiplicador + " = " + (numero * multiplicador)); multiplicador++; }

Ejemplo 5: Productos en carrito

let carrito = 0; let producto = prompt("Ingresa precio (0 para terminar):"); while (producto != 0) { carrito += parseFloat(producto); producto = prompt("Ingresa precio (0 para terminar):"); } console.log("Total: $" + carrito);
