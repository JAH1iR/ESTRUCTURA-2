15 - Operadores Lógicos AND (&&)

¿Qué es el operador AND (&&)?

El operador AND (&&) retorna verdadero SOLO si todas las condiciones son verdaderas.

if (condición1 && condición2) { // se ejecuta si AMBAS son verdaderas }

Tabla de Verdad - AND (&&)

Condición 1 Condición 2 Resultado (&&)
Verdadero Verdadero Verdadero
Verdadero Falso Falso
Falso Verdadero Falso
Falso Falso Falso

Ejemplo 1: Acceso a una zona VIP

Se necesita ser mayor de 18 años Y tener entrada válida

let edad = 20; let tieneEntrada = true; if (edad >= 18 && tieneEntrada) { console.log("Bienvenido a la zona VIP"); } else { console.log("No puedes acceder"); }

Ejemplo 2: Contraseña segura

La contraseña debe tener al menos 8 caracteres Y contener números

let contraseña = "abc12345"; if (contraseña.length >= 8 && /\d/.test(contraseña)) { console.log("Contraseña segura"); } else { console.log("Contraseña no cumple requisitos"); }

Ejemplo 3: Rango de valores

Un número está en el rango 10-100 si es mayor O igual a 10 Y menor O igual a 100

let numero = 50; if (numero >= 10 && numero <= 100) { console.log("El número está en el rango"); } else { console.log("El número está fuera del rango"); }

Ejemplo 4: Múltiples condiciones

Obtener descuento si tienes más de 5 compras Y tu gasto es mayor a $100

let compras = 6; let gasto = 150; if (compras > 5 && gasto > 100) { console.log("¡Tienes 20% de descuento!"); } else { console.log("No aplica descuento"); }
