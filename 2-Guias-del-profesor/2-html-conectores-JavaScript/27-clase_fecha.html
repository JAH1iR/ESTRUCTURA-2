27 - Objeto Date (Fechas en JavaScript)

¿Qué es el objeto Date?

El objeto Date de JavaScript permite trabajar con fechas y horas. Es un objeto especial integrado en JavaScript.

let fecha = new Date(); // Fecha y hora actual console.log(fecha);

Crear Fechas

// Fecha actual let ahora = new Date(); // Fecha específica (año, mes, día, hora, minuto, segundo) let fecha = new Date(2024, 0, 15); // 15 de enero de 2024 // Fecha desde string let fecha2 = new Date("2024-01-15"); // Desde milisegundos let fecha3 = new Date(1705276800000);

Ejemplo 1: Obtener fecha actual

let fecha = new Date(); console.log(fecha); // Ej: Mon Jan 15 2024 14:30:45 GMT-0500

Ejemplo 2: Métodos para obtener partes de la fecha

let fecha = new Date(); console.log(fecha.getFullYear()); // 2024 console.log(fecha.getMonth()); // 0-11 (0=enero, 11=diciembre) console.log(fecha.getDate()); // 1-31 (día del mes) console.log(fecha.getDay()); // 0-6 (0=domingo, 6=sábado) console.log(fecha.getHours()); // 0-23 (horas) console.log(fecha.getMinutes()); // 0-59 (minutos) console.log(fecha.getSeconds()); // 0-59 (segundos)

Ejemplo 3: Calcular edad

let fechaNacimiento = new Date(1995, 5, 15); // 15 de junio de 1995 let hoy = new Date(); let edad = hoy.getFullYear() - fechaNacimiento.getFullYear(); console.log("Edad: " + edad + " años");

Ejemplo 4: Días entre dos fechas

let fecha1 = new Date(2024, 0, 1); // 1 de enero let fecha2 = new Date(2024, 0, 15); // 15 de enero let diferencia = fecha2 - fecha1; // Milisegundos let días = diferencia / (1000 * 60 * 60 * 24); // Convertir a días console.log("Días entre fechas: " + días);

Ejemplo 5: Formatear fecha

let fecha = new Date(); // Método toLocaleString() console.log(fecha.toLocaleString("es-ES")); // Salida: 15/1/2024, 14:30:45 // Método toLocaleDateString() console.log(fecha.toLocaleDateString("es-ES")); // Salida: 15/1/2024 // Método toLocaleTimeString() console.log(fecha.toLocaleTimeString("es-ES")); // Salida: 14:30:45

Tabla de Métodos Date útiles

Método Descripción
getFullYear() Retorna el año (ej: 2024)
getMonth() Retorna el mes (0-11)
getDate() Retorna el día del mes (1-31)
getDay() Retorna el día de la semana (0-6)
getHours() Retorna las horas (0-23)
getTime() Retorna milisegundos desde 1970
