63 - Fetch API - Método POST

¿Qué es POST?

POST es un método HTTP para enviar datos al servidor.

fetch(url, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(datos) }) .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error(error));

Diferencias principales: GET vs POST

GET POST
Obtener datos Enviar datos
Visible en URL En el body (oculto)
Menos seguro Más seguro
Sin body Con body

Métodos HTTP principales

  • GET: Obtener datos (no modifica servidor)
  • POST: Crear nuevo recurso
  • PUT: Actualizar recurso completo
  • PATCH: Actualizar parte de un recurso
  • DELETE: Eliminar recurso
