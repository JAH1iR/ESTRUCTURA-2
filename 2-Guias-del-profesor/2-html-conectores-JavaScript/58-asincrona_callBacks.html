58 - Callbacks (Funciones como parámetros)

¿Qué es un Callback?

Un callback es una función pasada como parámetro a otra función, para ser ejecutada después.

function operacion(a, b, callback) { const resultado = a + b; callback(resultado); // Ejecutar el callback } operacion(5, 3, function(res) { console.log("Resultado: " + res); });
