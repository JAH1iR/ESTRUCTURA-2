22 - Break y Continue

Break: Sale completamente del ciclo
Continue: Salta a la siguiente iteración

¿Qué es Break?

Break detiene el ciclo completamente.

for (let i = 1; i <= 10; i++) { if (i === 5) break; // Sale del ciclo cuando i es 5 console.log(i); } // Salida: 1 2 3 4

Ejemplo 1: Break - Encontrar número

Buscar número 7 en un arreglo y detener cuando lo encuentre

let numeros = [2, 4, 6, 7, 8, 9]; for (let i = 0; i < numeros.length; i++) { console.log("Revisando: " + numeros[i]); if (numeros[i] === 7) { console.log("¡Encontrado!"); break; } }

Ejemplo 2: Break en Switch

Break también se usa en Switch (ya lo viste) para evitar que siga ejecutando otros cases

switch (opcion) { case 1: console.log("Opción 1"); break; // Sin break, seguiría a case 2 case 2: console.log("Opción 2"); break; }

¿Qué es Continue?

Continue salta a la siguiente iteración del ciclo.

for (let i = 1; i <= 10; i++) { if (i === 5) continue; // Salta la iteración cuando i es 5 console.log(i); } // Salida: 1 2 3 4 6 7 8 9 10 (falta el 5)

Ejemplo 3: Continue - Omitir pares

Imprimir solo números impares saltando los pares

for (let i = 1; i <= 10; i++) { if (i % 2 === 0) continue; // Si es par, salta console.log(i); // Solo impares } // Salida: 1 3 5 7 9

Ejemplo 4: Continue - Saltar emails inválidos

Procesar solo emails que contengan "@"

let emails = ["juan@mail.com", "invalido", "ana@gmail.com", "nomail"]; for (let i = 0; i < emails.length; i++) { if (!emails[i].includes("@")) continue; console.log("Procesando: " + emails[i]); }

Ejemplo 5: Break - Contraseña correcta

Permitir 3 intentos de contraseña

let intentos = 0; let contraseña = "1234"; let maxIntentos = 3; for (let i = 1; i <= 5; i++) { let ingresada = prompt("Contraseña:"); if (ingresada === contraseña) { console.log("✓ Acceso permitido"); break; // Sale del ciclo } else if (i === maxIntentos) { console.log("✗ Demasiados intentos"); break; } }

Comparación: Break vs Continue

Break Continue
Sale completamente del ciclo Salta a la siguiente iteración
El ciclo termina El ciclo continúa
for (i=1; i<=10; i++) if (i===5) break; → 1 2 3 4 for (i=1; i<=10; i++) if (i===5) continue; → 1 2 3 4 6 7 8 9 10
