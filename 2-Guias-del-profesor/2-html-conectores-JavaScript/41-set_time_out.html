41 - setTimeout y setInterval

setTimeout - Ejecutar después de un tiempo

setTimeout(función, milisegundos); // Ejecuta la función una sola vez después de X milisegundos

setInterval - Ejecutar repetidamente

let id = setInterval(función, milisegundos); // Ejecuta la función cada X milisegundos // Guardar el id para poder detener después con clearInterval()
