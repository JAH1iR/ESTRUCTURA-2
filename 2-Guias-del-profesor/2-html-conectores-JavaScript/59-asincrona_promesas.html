59 - Promesas en JavaScript

¿Qué es una Promesa?

Una promesa representa el resultado eventual de una operación asincrónica.

Estados:

  • Pending (Pendiente): La operación está en progreso
  • Fulfilled (Resuelta): La operación se completó exitosamente
  • Rejected (Rechazada): La operación falló

Sintaxis básica

new Promise((resolve, reject) => { if (condición) { resolve("Éxito"); // Promesa resuelta } else { reject("Error"); // Promesa rechazada } }) .then(resultado => console.log(resultado)) .catch(error => console.error(error));
