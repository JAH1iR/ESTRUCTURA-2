19 - Ciclo Do-While

Diferencia importante:
While: Verifica la condición PRIMERO, luego ejecuta
Do-While: Ejecuta el bloque PRIMERO, luego verifica

¿Qué es un ciclo Do-While?

Un ciclo do-while repite un bloque de código al menos una vez, y después verifica la condición.

do { // código a repetir (se ejecuta AL MENOS UNA VEZ) } while (condición);

Ejemplo 1: Imprimir números (Do-While vs While)

Do-While - se ejecuta al menos una vez aunque la condición sea falsa desde el inicio

let i = 1; do { console.log(i); i++; } while (i <= 5);

Ejemplo 2: Menú de usuario (diferencia clave)

Do-While es perfecto para menús porque se muestra al menos una vez

let opcion; do { opcion = prompt("1-Jugar, 2-Salir, 3-Configuración"); switch(opcion) { case '1': console.log("Iniciando juego..."); break; case '2': console.log("Adiós"); break; case '3': console.log("Abriendo configuración..."); break; default: console.log("Opción inválida"); } } while (opcion !== '2');

Ejemplo 3: Validación de entrada

Pedir un número hasta que sea válido (entre 1 y 100)

let numero; do { numero = prompt("Ingresa número entre 1-100:"); if (numero < 1 || numero > 100) { console.log("Inválido, intenta de nuevo"); } } while (numero < 1 || numero > 100); console.log("Número válido: " + numero);

Ejemplo 4: Sumar números con Do-While

let suma = 0; let i = 1; do { suma += i; i++; } while (i <= 5); console.log("Suma: " + suma);

Ejemplo 5: Comparación While vs Do-While

Cuando la condición es falsa desde el inicio:

// While: no ejecuta nada while (false) { console.log("No se ejecuta"); } // Do-While: se ejecuta una vez do { console.log("Se ejecuta una vez"); } while (false);
