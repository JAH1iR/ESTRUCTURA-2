64 - Métodos HTTP: PUT, PATCH, DELETE

Métodos HTTP CRUD

Método Acción Descripción
GET Read Obtener datos
POST Create Crear nuevo recurso
PUT Update Actualizar todo el recurso
PATCH Partial Update Actualizar parte del recurso
DELETE Delete Eliminar recurso

Ejemplo 1: PUT (actualizar completamente)

fetch('url/id', { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(datosCompletos) })

Ejemplo 2: PATCH (actualizar parcialmente)

fetch('url/id', { method: 'PATCH', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ email: 'nuevo@ejemplo.com' }) })

Ejemplo 3: DELETE (eliminar)

fetch('url/id', { method: 'DELETE' })

Diferencia PUT vs PATCH

PUT: Requiere todos los datos del recurso

PATCH: Solo requiere los datos a actualizar
