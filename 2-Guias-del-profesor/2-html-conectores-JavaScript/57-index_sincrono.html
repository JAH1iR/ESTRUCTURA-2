57 - Asincronía: Síncrono vs Asincrónico

¿Qué es Asincronía?

Síncrono: El código espera a que termine una operación antes de continuar

Asincrónico: El código continúa ejecutándose sin esperar a que termine una operación

Ejemplo 1: Código Síncrono (se espera)

console.log("Inicio"); console.log("Operación 1"); console.log("Operación 2"); console.log("Fin"); // Salida esperada: // Inicio // Operación 1 // Operación 2 // Fin

Ejemplo 2: Código Asincrónico (no se espera)

console.log("Inicio"); setTimeout(() => { console.log("Operación (después de 2s)"); }, 2000); console.log("Fin"); // Salida esperada: // Inicio // Fin // Operación (después de 2s)

Ejemplo 3: Callbacks (función como parámetro)

function saludar(nombre, callback) { console.log("Hola " + nombre); callback(); // Ejecutar la función callback } saludar("Juan", function() { console.log("Soy el callback"); });

El problema del Callback Hell

Cuando tienes muchos callbacks anidados, el código se vuelve difícil de leer (pirámide de doom)

function tarea1(callback) { ... } function tarea2(callback) { ... } function tarea3(callback) { ... } tarea1(function() { tarea2(function() { tarea3(function() { console.log("Hecho"); }); }); }); // Difícil de leer
