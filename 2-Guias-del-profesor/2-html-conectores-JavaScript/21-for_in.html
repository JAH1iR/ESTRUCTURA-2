21 - Ciclo For-In

¿Qué es For-In?

For-In es un ciclo que itera sobre las PROPIEDADES (llaves) de un objeto o arreglo.

for (let clave in objeto) { // clave contiene el nombre de la propiedad // objeto[clave] accede al valor }

Ejemplo 1: Recorrer propiedades de un objeto

let persona = { nombre: "Juan", edad: 30, ciudad: "Madrid" }; for (let propiedad in persona) { console.log(propiedad + ": " + persona[propiedad]); } // Salida: // nombre: Juan // edad: 30 // ciudad: Madrid

Ejemplo 2: Recorrer elementos de un arreglo

let colores = ["rojo", "azul", "verde"]; for (let indice in colores) { console.log(indice + ": " + colores[indice]); } // Salida: // 0: rojo // 1: azul // 2: verde

Ejemplo 3: Auto (objeto con múltiples propiedades)

let auto = { marca: "Toyota", modelo: "Corolla", año: 2022, color: "gris", velocidadMaxima: 180 }; for (let atributo in auto) { console.log(atributo + ": " + auto[atributo]); }

Ejemplo 4: Arreglo de objetos

let estudiantes = [ { nombre: "Ana", nota: 85 }, { nombre: "Bob", nota: 90 }, { nombre: "Carlos", nota: 78 } ]; for (let i = 0; i < estudiantes.length; i++) { for (let propiedad in estudiantes[i]) { console.log(propiedad + ": " + estudiantes[i][propiedad]); } console.log("---"); }

Diferencia: For-In vs For normal

For: itera sobre índices (0, 1, 2...)

For-In: itera sobre propiedades (claves del objeto)

let frutas = ["manzana", "plátano", "naranja"]; // For normal for (let i = 0; i < frutas.length; i++) { console.log(i, frutas[i]); // índice y valor } // For-In for (let indice in frutas) { console.log(indice, frutas[indice]); // similar pero diferente }
