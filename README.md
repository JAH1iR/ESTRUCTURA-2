## Extensiones recomendadas para VS Code

Para trabajar sin problemas con este curso de frontend, especialmente con HTML, CSS y JavaScript, recomiendo estas extensiones en Visual Studio Code:

### Esenciales

* **Live Server**: permite abrir HTML en un navegador local y recargar automáticamente al guardar cambios.
* **Prettier - Code formatter**: formatea automáticamente el código para mantenerlo limpio y legible.
* **ESLint**: ayuda a detectar errores, malas prácticas y sugerencias de mejora en JavaScript.
* **Auto Close Tag**: cierra etiquetas HTML y JSX automáticamente.
* **Auto Rename Tag**: renombra la etiqueta de cierre al cambiar la de apertura.
* **HTML CSS Support**: ayuda con autocompletado y soporte de clases CSS dentro de archivos HTML.
* **IntelliSense for CSS class names in HTML**: sugiere nombres de clases CSS en HTML.
* **JavaScript (ES6) code snippets**: agrega fragmentos útiles para escribir JavaScript más rápido.

### Opcionales pero útiles

* **GitHub Copilot**: ayuda a generar código, explicar conceptos y acelerar el aprendizaje.
* **Material Icon Theme**: mejora la visualización del explorador de archivos.
* **Bracket Pair Colorizer**: ayuda a identificar mejor los bloques de código.
* **Code Runner**: ejecuta rápidamente fragmentos pequeños de JavaScript y pruebas rápidas.
* **Path Intellisense**: facilita la escritura de rutas relativas en HTML, CSS y JS.
* **TODO Highlight**: ayuda a marcar tareas pendientes o comentarios importantes.

### Para comodidad y flujo de trabajo personal

Estas son las que suelen hacer el trabajo más cómodo y ordenado según el estilo de desarrollo diario:

* **GitHub Copilot**: ideal para aclarar dudas, generar ejemplos y acelerar la escritura de código.
* **Prettier**: mantiene todo formateado y consistente.
* **Live Server**: para ver cambios en HTML y CSS en tiempo real.
* **ESLint**: ayuda a detectar errores de sintaxis y mejores prácticas.
* **Material Icon Theme**: mejora la organización visual del proyecto.
* **Bracket Pair Colorizer**: facilita leer bloques complejos de código.
* **Path Intellisense**: ahorra tiempo cuando se trabajan rutas y archivos locales.

### Recomendación práctica

Si quieres empezar con lo mínimo para este curso, estas son las que considero más importantes:

1. Live Server
2. Prettier
