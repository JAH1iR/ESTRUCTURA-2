# Documentación del material de estructura de datos 2

Repositorio dedicado al estudio y práctica de fundamentos web, estructurado por módulos de aprendizaje y componentes técnicos basicos.

## Organización del Repositorio

### Maquetación y Estilos (CSS)
* **css-flexbox**: Implementación de layouts unidimensionales y alineación de contenedores.
* **css-grid**: Diseño de rejillas bidimensionales y estructuras de página complejas.
* **cssd-box-model**: Pruebas sobre el modelo de caja: dimensiones, márgenes, bordes y relleno.

### Lógica y Estructura (HTML/JS)
* **html**: Desarrollo de la estructura semántica y marcado de documentos.
* **js**: Ejercicios de lógica de programación, sintaxis.
* **js-del-profe**: Recursos externos, ejemplos de clase y guías proporcionadas por el profe.

### Componentes y Semántica
* **etiquetas-semanticas**: Aplicación de estándares HTML5 para la definición de secciones de contenido (header, nav, main, section, footer).

## Entorno de Desarrollo
* **Editor**: Visual Studio Code.
* **Control de Versiones**: Git / GitHub.
* **Metodología**: Sincronización continua entre dispositivos mediante repositorio remoto.
